# research-yths

Plugin gồm 2 skill:

- `research-yths:topic-deep-dive` — tìm hiểu đề tài, công việc, công ty hoặc vấn đề, rồi làm báo cáo: hiện trạng → vấn đề → các cách giải quyết hiện có → giải pháp tối ưu, có dẫn chứng link từ nguồn gốc.
- `research-yths:vietnamese-readability-review` — rà tiếng Việt cho dễ hiểu theo checklist 12 lỗi; báo cáo dùng giọng trung tính.

## Cài đặt

```
/plugin marketplace add Hoangthais034/research-yths
/plugin install research-yths@research-yths
```
